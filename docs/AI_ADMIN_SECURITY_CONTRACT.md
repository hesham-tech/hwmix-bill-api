# عقد إدارة منصة AI

نطاق هذا التغيير: `/api/v1/ai/admin/*` وصفحات `/ai-platform*` فقط. مسارات تشغيل القدرات والمحادثات وWorkflow وسياساتها لا تتغير.

- المصادقة `auth:sanctum` و`admin.super` إلزاميتان على المسارات الإدارية الـ23، حتى عند تخصيص middleware المجموعة الخارجية. الضيف401، والموظف ومدير الشركة403 قبل الوصول إلى بيانات AI. لا توسيع لصلاحيات إدارة الشركات.
- الشركة هي `user.active_company_id` بعد المصادقة، وليست افتراضيًا1 أو قيمة يختارها الطلب. تتطلب العمليات الخاصة بالشركة وجود شركة غير محذوفة؛ غياب الاختيار الصالح422، وقد يرفض middleware الشركة العام شركة معطلة أو محذوفة بـ403 قبل ذلك. إن أُرسل company_id يجب أن يطابق الشركة النشطة وإلا403؛ تبديل الشركة يتم بالآلية القائمة أولًا.
- النماذج المشتركة يديرها مدير النظام دون اشتراط شركة نشطة. حسابات المزودين والقوالب تستخدم نطاق الشركة افتراضيًا. `is_system=true` في JSON أو `is_system=1` في query يحدد السجلات العامة صراحةً لمدير النظام، ولا ينقل ملكية سجل شركة إلى النظام أو العكس. القيم غير المنطقية422. لا API لنقل ملكية سجلات.
- قائمة القوالب تتضمن قوالب الشركة والعامة كما سابقًا؛ تعديل/حذف/تبديل سجل عام يحتاج تحديد نطاق النظام صراحةً. غياب السجل في النطاق404، بما فيه معرف موجود في شركة أخرى. استجابة النجاح وأسماء المسارات القائمة محفوظة.
- FormRequests منفصلة للنماذج والحسابات والوكلاء والقوالب تتحقق من أنواع الحقول وحدودها قبل الكتابة. لا تُمرر حقول الشركة والنطاق ومعلومات العلاقات إلى mass assignment. إنشاء حساب الشركة يثبت account_scope=COMPANY، والعام SYSTEM. لا تغيير schema أو تبعيات.
- الواجهة تضيف permission إلى المسارات الستة، وترسل scope للسجلات العامة دون إعادة company_id من استجابة قديمة إلى الطلب. هذه إضافة لتحسين تجربة الاستخدام؛ الحماية الفعلية على الخادم.

## حدود الوظائف والتحقق

هذه معالجة لتفويض الإدارة ونطاقها، وليست إعلان جاهزية وظائف AI كاملة. توجد اختلافات قديمة بين حقول حفظ prompts/agents والمهاجرات: prompts يحتاج type/label ولا يعرّف title/description؛ agents لا يعرّف system_prompt. لا تضف أعمدة أو تختار تصميم تخزين جديدًا ضمن تغيير التفويض. اختبارات المخطط تستخدم المهاجرات القائمة وتوثق متابعة توافق CRUD بصورة مستقلة. تصفية أسرار نماذج الحسابات والتقييد الشبكي لعناوين المزودين ومحرك التنفيذ الخلفي أعمال منفصلة.

## التسليم والتراجع

نُفذت الفحوص محليًا فقط بقاعدة ذاكرة وبيانات مصطنعة وSecretVault وهمي، والمتصفح يتصل localhost فقط مع API محاكاة. لا اختبار إنتاج أو staging أو مزود حقيقي، ولا إثبات لأداء MySQL من SQLite. الرفع والنشر منفصلان خارج هذه المهمة. عند التسليم يراجع المشغل تغييرات الإنتاج الجديدة قبل دمج/رفع لاحق؛ لا يتراجع إلى فتح الإدارة للمستخدم العادي. يمكن تعطيل المجموعة الإدارية مؤقتًا مع إبقاء auth والتفويض. لا migration أو DB restore مطلوب للتراجع عن هذا الكود.
